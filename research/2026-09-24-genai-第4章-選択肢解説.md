## g4-01 著作権法第30条の4

**問題**: 著作権法第30条の4に関する説明として正しいものはどれ？
選択肢: (0)原則許諾不要（正解） / (1)全員の許諾が必要 / (2)AI生成物は全て著作権フリー / (3)海外の著作物は学習に使えない

### 事実

- **条文本体**（引用、文化庁資料内での明示的引用による）:
  「著作物は、当該著作物に表現された思想又は感情を自ら享受し又は他人に享受させることを目的としない場合には、その必要と認められる限度において、利用することができる」（法第30条の4柱書）。第2号で「情報解析（多数の著作物その他の大量の情報から、当該情報を構成する言語、音、影像その他の要素に係る情報を抽出し、比較、分類その他の解析を行うことをいう）の用に供する場合」を典型例として明示。
  ただし書：「当該著作物の種類及び用途並びに当該利用の態様に照らし著作権者の利益を不当に害することとなる場合は、この限りでない。」
  - 出典: [文化庁「AIと著作権に関する考え方について」（令和6年3月15日）](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/pdf/94037901_01.pdf) p.9-10／[e-Gov法令検索](https://laws.e-gov.go.jp/law/345AC0000000048)（条文自体はJS表示のため本文取得不可、文化庁資料の引用で確認）
  - 確度: 高（一次資料での引用を確認。e-Gov本体は自動取得できなかったが、文化庁資料が条文を直接引用している）

- **「享受」の意味**: 「精神的にすぐれたものや物質上の利益などを、受け入れ味わい楽しむこと」（広辞苑第七版）。著作物等の視聴等を通じて知的・精神的欲求を満たす効用を得ることに向けられた行為か否かで判断。
  - 出典: 同上 p.10
  - 確度: 高

- **学習段階と生成・利用段階の整理**: 文化庁資料は「開発・学習段階」（AI学習のための複製等。原則30条の4の対象）と「生成・利用段階」（生成物の生成・利用。既存著作物との**類似性・依拠性**が認められれば通常の著作権侵害と同じ基準で判断）を明確に区別している。
  - 出典: 同上 p.17（5.各論点について（1）開発・学習段階）、p.32（（2）生成・利用段階）
  - 確度: 高

- **誤答②「AI生成物は全て著作権フリー」が誤りである根拠**: AI生成物が著作物に該当するかは通常の著作物の定義（法第2条第1項第1号：思想又は感情の創作的表現）で判断される。AI自身は法的人格を持たないため著作者になれないが、人間の創作的寄与（指示の具体性、生成物を確認しながらの試行の繰り返し、複数生成物からの選択の組み合わせ等）が認められれば、AI生成物は著作物となり著作権が発生しうる。単なる労力だけでは創作的寄与にならない。
  - 出典: 同上 p.39-40（5.（3）生成物の著作物性について）
  - 確度: 高

- **誤答④「海外の著作物は学習に使えない」が誤りである根拠**: 法第30条の4は著作物の国籍（内国民の著作物か外国の著作物か）を要件として区別していない。文化庁資料では「準拠法決定の問題」として、著作物等の利用行為（学習・生成・送信等）が日本国内で行われた/結果が日本国内で発生したと評価される場合に日本の著作権法（30条の4を含む）が適用されると考えられる、という整理がされている。つまり国籍で一律に排除されるのではなく、利用行為の行われた場所等によって準拠法が決まる。
  - 出典: 同上 p.5-8（2.（1）エ 我が国の著作権法が適用される範囲）
  - 確度: 高

- **誤答①「全員の許諾が必要」が誤りである根拠**: 上記の通り、情報解析目的（AI学習を含む）の利用は原則として権利制限規定（30条の4）により許諾不要。ただし書に該当する場合や、享受目的が併存する場合（例: 意図的な過学習で著作物の創作的表現をそのまま出力させる場合）は適用除外となり許諾が必要になる。
  - 出典: 同上 p.19-29
  - 確度: 高

### 出題の狙い（想定される引っかけ）
- 「学習は原則自由」という点だけを覚えていると、「ただし書」（著作権者の利益を不当に害する場合は適用除外）を忘れやすい。
- 「AI生成物＝著作権フリー」という俗説と、実際には人間の創作的寄与があれば著作物になりうるという整理を混同しやすい。
- 「30条の4は日本の著作物だけに適用される」という誤解（実際は国籍で区別せず、利用行為地等で準拠法を判断）。

## g4-02 類似性と依拠性

**問題**: AI生成物が著作権侵害にあたるかを判断する2要件は？
選択肢: (0)類似性と依拠性（正解） / (1)新規性と進歩性 / (2)公開性と営利性 / (3)独創性と大衆性

### 事実

- **類似性・依拠性という2要件**: 文化庁資料は「既存の判例では、ある作品に、既存の著作物との類似性と依拠性の両者が認められる際に、著作権侵害となるとされている」と明記。生成AIの生成物についても同じ基準で判断されるとする。
  - 類似性の判断基準の根拠判例: 最判平成13年6月28日〔江差追分事件〕
  - 依拠性の判断基準の根拠判例: 最判昭和53年9月7日〔ワン・レイニー・ナイト・イン・トーキョー事件〕
  - 出典: [文化庁「AIと著作権に関する考え方について」](https://www.bunka.go.jp/seisaku/bunkashingikai/chosakuken/pdf/94037901_01.pdf) p.32-38
  - 確度: 高

- **誤答①「新規性と進歩性」**: これは著作権法の用語ではなく、**特許法**上の特許要件（特許法第29条第1項・第2項）。新規性＝出願前に公知・公用・刊行物記載等でないこと、進歩性＝当業者が先行技術から容易に発明できたものでないこと。
  - 出典: [特許庁「特許・実用新案審査基準 第III部第2章 新規性・進歩性」](https://www.jpo.go.jp/system/laws/rule/guideline/patent/tukujitu_kijun/ht/03_0200.html)
  - 確度: 高（特許庁公式審査基準）

- **誤答②「公開性と営利性」、誤答③「独創性と大衆性」**: 文化庁「AIと著作権に関する考え方について」（著作権侵害の判断基準を扱う一次資料）には、これらの語は著作権侵害の判断要件として登場しない。著作権法・特許法のいずれにおいても、これらが確立した法律要件として使われている用例は確認できなかった。
  - 確度: **中**（「文化庁資料に用例がない」ことは確認できたが、他のあらゆる法令・学説を網羅的に確認したわけではないため、「存在しない」と断定する根拠としては中程度。作問時は「著作権侵害の判断要件としては使われていない」という限定で使うのが安全）

### 出題の狙い（想定される引っかけ）
- 特許法の「新規性・進歩性」と著作権法の「類似性・依拠性」を混同させる（省庁・法律をまたいだ紛らわしい選択肢）。
- 「独創性」や「営利性」は日常語として著作権のニュースでも使われがちだが、侵害の判断要件そのものではない点に注意。

## g4-03 生成AIの業務利用・入力時の注意

**問題**: 生成AIの業務利用で入力時に最も注意すべきことは？
選択肢: (0)機密情報や個人情報を安易に入力しない（正解） / (1)長い文章を入力しない / (2)英語で入力しない / (3)同じ質問を2回しない

### 事実

- **個人情報保護委員会「生成AIサービスの利用に関する注意喚起等について」（令和5年6月2日）** の要点（別添1より原文引用）:
  - 個人情報取扱事業者：「生成AIサービスに個人情報を含むプロンプトを入力する場合には、特定された当該個人情報の利用目的を達成するために必要な範囲内であることを十分に確認すること」。無断で個人データを含むプロンプトを入力し、出力以外の目的で取り扱われる場合は個人情報保護法違反となる可能性があり、「当該生成AIサービスを提供する事業者が、当該個人データを機械学習に利用しないこと等を十分に確認すること」。
  - 一般の利用者：「入力された個人情報が、生成AIの機械学習に利用されることがあり、他の情報と統計的に結びついた上で、また、正確又は不正確な内容で、生成AIサービスから出力されるリスクがある」「生成AIサービスを提供する事業者の利用規約やプライバシーポリシー等を十分に確認」すること。
  - 同日、ChatGPTを開発・提供するOpenAI, L.L.C.及びOpenAI OpCo, LLCに対しても、個人情報保護法第147条に基づき、要配慮個人情報の取得や利用目的の通知等について注意喚起を実施。
  - 出典: [個人情報保護委員会 報道発表（令和5年6月2日）](https://www.ppc.go.jp/news/press/2023/230602kouhou/)、[別添PDF本文](https://www.ppc.go.jp/files/pdf/230602_kouhou_houdou.pdf)
  - 確度: 高（一次資料、全文確認済み）

- **AI事業者ガイドライン（AI利用者向け）**: 総務省・経済産業省の「AI事業者ガイドライン」にもAI利用者向けの機密情報・個人情報の取扱いに関する記載があるとされるが、原文の該当箇所を今回直接確認できなかった（PDFの直接取得がブロックされたため）。
  - 確度: **未確認**（存在自体は複数の解説記事で言及されているが、一次資料の原文引用はできていない。作問には個人情報保護委員会の資料の方を使うのが安全）

- **誤答①②③（長文・英語・再質問）が注意点でない根拠**: 個人情報保護委員会の注意喚起は「入力する情報の内容」（個人情報・機密情報が含まれるか）に焦点を当てており、文章の長さ・言語・再質問の有無を問題にしていない。

### 出題の狙い（想定される引っかけ）
- 「学習に使われるリスク」と「情報漏えいリスク」を区別できるか。
- 個人情報保護法上、事業者が「本人の同意なく」個人データを入力し、応答目的以外で使われる場合に法違反となりうる、という「事業者側の責任」の視点が問われやすい。

## g4-06 AI推進法（AI新法）

**問題**: 2025年に成立した「AI新法（AI推進法）」の特徴として正しいものは？
選択肢: (0)研究開発と活用の推進が目的、罰則規定なし（正解） / (1)生成AIを全面禁止 / (2)高額な制裁金 / (3)開発を許可制に

### 事実

- **正式名称**: 「人工知能関連技術の研究開発及び活用の推進に関する法律」（令和7年法律第53号）。
  - 出典: [e-Gov法令検索（法令番号ページ）](https://laws.e-gov.go.jp/law/507AC0000000053)、[内閣府AI法ページ](https://www8.cao.go.jp/cstp/ai/ai_act/ai_act.html)
  - 確度: 高

- **成立・公布・施行の日付**:
  - 成立: 令和7年5月28日（2025年5月28日、参議院本会議で可決・成立）
  - 公布・一部施行: 令和7年6月4日（2025年6月4日、法律第53号として公布。AI基本計画・AI戦略本部関連規定を除く部分はこの日に施行）
  - 全面施行: 令和7年9月1日（2025年9月1日、AI戦略本部設置規定等を含め全面施行）
  - 出典: [内閣府「AI法 全面施行－次なるフェーズへ－」（2025年10月3日記事）](https://www.cao.go.jp/press/new_wave/20251003.html)、[国立国会図書館カレントアウェアネス](https://current.ndl.go.jp/car/253410)
  - 確度: 高

- **法律の目的・基本理念（内閣府公式の法案概要より原文）**: 目的＝「国民生活の向上、国民経済の発展」。基本理念には「経済社会及び安全保障上重要な研究開発力の保持、国際競争力の向上」「基礎研究から活用まで総合的・計画的に推進」「適正な研究開発・活用のため透明性の確保等」「国際協力において主導的役割」。
  - 出典: [内閣府「AI法案 概要」PDF](https://www.cao.go.jp/houan/pdf/217/217gaiyou_2.pdf)
  - 確度: 高（一次資料、全文確認済み）

- **AI戦略本部・AI基本計画（同上概要PDFより）**:
  - AI戦略本部: 本部長＝**内閣総理大臣**、構成員＝**全閣僚**。関係行政機関等に必要な協力を求める権限を持つ。

## g4-07 EU AI法（AI Act）

**問題**: EU AI法の特徴として正しいものは？
選択肢: (0)リスクベースアプローチ（正解） / (1)全AIを同じ基準で禁止 / (2)EU域外企業には一切適用されない / (3)罰則のないガイドラインのみ

### 事実

- **リスクベースアプローチ**: AIをリスクの大きさで「許容できないリスク（禁止）」「高リスク」「限定的リスク（透明性義務）」「最小リスク」の4段階に分類し、段階に応じて義務を課す。
  - 確度: 高（複数の解説記事で一致。EU公式条文（Regulation (EU) 2024/1689）の構造として広く知られる内容だが、今回EUR-Lex原文の直接確認はできていないため確度は「高」だが一次資料の直接引用ではない点に留意）

- **域外適用**: EU域内に拠点を置く事業者だけでなく、EU域外の事業者がEU市場にAIシステムを投入・提供する場合や、AIシステムの出力がEU域内で使用される場合も適用対象となる（第2条の適用範囲）。EU域外で高リスクAIを提供する事業者はEU域内の法定代理人（Authorised Representative）の選任が必要とされる。
  - 確度: 中（複数の法律事務所・コンサル系サイトの解説に基づく。EUR-Lex原文の直接確認はできていない）

- **罰則（制裁金）**: 第99条により、禁止AI（第5条）違反は最大3,500万ユーロまたは全世界年間売上高の7%のいずれか高い方、その他の義務違反は最大1,500万ユーロまたは3%、当局への誤った情報提供等は最大750万ユーロまたは1%。中小企業は「higher」ではなく「lower」の方が適用される特例がある。
  - 出典: [artificialintelligenceact.eu Article 99](https://artificialintelligenceact.eu/article/99/) 等の条文解説サイト（EUR-Lex原文は今回直接確認できず）
  - 確度: 中（複数の独立した条文解説サイトの記載が一致しているが、EUR-Lex一次資料への直接アクセスはできていない）

- **適用スケジュール（2026年9月24日時点の状況、重要な最新動向）**:
  - 2024年8月1日: AI法（Regulation (EU) 2024/1689）発効。
  - 2025年2月2日: 禁止AI（第5条）に関する規定の適用開始。
  - 2025年8月2日: 汎用目的AI（GPAI）モデルに関する規定の適用開始。
  - 当初は2026年8月2日に高リスクAI（附属書III）等を含む大部分の規定が適用開始予定だった。
  - **2025年11月19日、欧州委員会が「デジタル・オムニバス（Digital Omnibus on AI）」を提案**。高リスクAI義務の適用開始を**2026年8月2日から2027年12月2日（附属書IIIのスタンドアロン高リスクAIシステム）**に延期する内容。附属書I（他の規制対象製品に組み込まれたAI）は2028年8月2日まで延期。
  - 2026年5月7日: 欧州議会・理事会が暫定合意。2026年6月29日: 理事会が最終承認（複数の法律事務所解説による）。
  - 第50条の透明性義務（AI生成物であることの明示等）は延期対象外で、2026年8月から適用される、との解説もある。
  - 出典: [Gibson Dunn解説](https://www.gibsondunn.com/eu-ai-act-omnibus-agreement-postponed-high-risk-deadlines-and-other-key-changes/)、[DLA Piper GENIE解説](https://knowledge.dlapiper.com/dlapiperknowledge/globalemploymentlatestdevelopments/2026/The-Digital-AI-Omnibus-Proposed-deferral-of-high-risk-AI-obligations-under-the-AI-Act)、[Cloud Security Alliance研究ノート](https://labs.cloudsecurityalliance.org/research/csa-research-note-eu-ai-act-high-risk-deadline-omnibus-20260/)、[EU理事会プレスリリース（タイトルのみ確認、本文403で直接取得不可）](https://www.consilium.europa.eu/en/press/press-releases/2026/06/29/artificial-intelligence-council-gives-final-green-light-to-simplify-and-streamline-rules/)
  - 確度: **中**（複数の独立した法律事務所・コンプライアンス専門サイトが同じ内容を報じており信頼性は比較的高いが、欧州委員会・EU理事会の公式ページ本文を直接取得できず、一次資料での確認ができていない。**作問時は「高リスクAI義務は延期の動きがある」という事実は要検証として扱い、断定的な出題は避けるべき**）

- **誤答①「全てのAIを同じ基準で禁止」が誤りである根拠**: リスクベースであり、禁止対象は「許容できないリスク」の一部のみ（例：社会的スコアリング、標的型の潜在意識操作等）。
- **誤答②「EU域外企業には一切適用されない」が誤りである根拠**: 上記の域外適用規定により誤り。
- **誤答③「罰則のないガイドラインのみ」が誤りである根拠**: AI法はEUの規則（Regulation）であり、加盟国に直接効力を持つ法規範。第99条に具体的な制裁金（罰則）規定がある点でガイドラインとは異なる。

### 既存問題の確認結果
- 既存の問題文・e自体（リスクベースアプローチの説明）は正しい。ただし、2026年9月24日時点で「高リスクAI義務の適用が延期されている」という最新動向は選択肢・解説に含まれておらず、もし今後この点を出題するなら「デジタル・オムニバスによる延期」の事実（確度：中）を明示した上で出題する必要がある。

### 出題の狙い（想定される引っかけ）
- 「EU域外だから関係ない」という誤解（域外適用がある）。
- 制裁金の具体的な金額（3,500万ユーロ／7%など）を、日本のAI推進法（罰則なし）と対比させる出題は効果的だが、EU側の金額は確度中のため、断定的な数字を問う出題は要検証。

## g4-08 ディープフェイク／フィッシング／スパム／ハルシネーション

**問題**: 実在の人物の顔・声を本物そっくりに合成した偽の映像・音声を何という？
選択肢: (0)ディープフェイク（正解） / (1)フィッシング / (2)スパム / (3)ハルシネーション

### 事実

- **ディープフェイク**: 生成AI・ディープラーニング技術を用いて人物の顔や声を合成し、本物そっくりの偽の映像・音声を作成する技術・生成物を指す。日本でも生成AIで作成された首相の偽動画がSNS上で拡散した事例がある。総務省は「令和6年版情報通信白書」で偽・誤情報の流通・拡散の課題として取り上げている。
  - 出典: [総務省 令和6年版情報通信白書](https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r06/html/nd141210.html)
  - 確度: 中〜高（総務省白書での言及は確認できたが、白書内の「ディープフェイク」の厳密な定義文そのものの引用は今回未確認。技術的な説明自体は多数の解説記事で一致）

- **フィッシング**: 送信者を詐称したメールやSMSを送りつけ、貼り付けたリンクをクリックさせて偽のホームページに誘導し、クレジットカード番号やID・パスワード等の重要情報を盗み出す詐欺。
  - 出典: [総務省「国民のためのサイバーセキュリティサイト」フィッシング詐欺とは](https://www.soumu.go.jp/main_sosiki/cybersecurity/kokumin/basic/risk/04/)、[フィッシング対策協議会](https://www.antiphishing.jp/consumer/abt_phishing.html)
  - 確度: 高

- **スパム（迷惑メール）**: 法律上「スパム」という単語自体は使われていないが、「特定電子メールの送信の適正化等に関する法律」（特定電子メール法）が、受信者の事前同意（オプトイン）なしに広告・宣伝の電子メールを送ることを原則禁止する形で迷惑メールを規制している。違反時は最大1年以下の懲役または100万円以下の罰金。
  - 出典: [消費者庁「特定電子メール法」](https://www.caa.go.jp/policies/policy/consumer_transaction/specifed_email)
  - 確度: 中（法律名・規制内容の大枠は消費者庁ページで確認したが、罰則の具体的な条文番号までは今回未確認）

- **ハルシネーション**: 生成AI（特にLLM）が、事実と異なる内容を、確率的な相関関係に基づいてもっともらしく生成してしまう現象。個人情報保護委員会の注意喚起（g4-03参照）でも「当該文章は確率的な相関関係に基づいて生成されるため、その応答結果には不正確な内容の個人情報が含まれるリスクがある」という形で、ハルシネーションに相当する現象が説明されている。AI事業者ガイドライン（第1.2版、2026年3月31日）も、ハルシネーションをAIのリスクの代表例として扱っている（RAG活用等がハルシネーション抑制に資するという記載がある）。
  - 出典: [個人情報保護委員会 注意喚起別添1](https://www.ppc.go.jp/files/pdf/230602_kouhou_houdou.pdf)（確度高、全文確認済み）／AI事業者ガイドラインでの扱いは検索結果の要約に基づくもので原文直接確認はできていない（確度中）

### 出題の狙い（想定される引っかけ）
- 「フィッシング」と「ディープフェイク」はいずれも「なりすまし」的要素があるため混同しやすいが、フィッシングは主に**詐欺目的の誘導（メール・偽サイト）**、ディープフェイクは**映像・音声の合成技術そのもの**という違いがある。
- 「スパム」は迷惑メール一般を指す通称であり、AIの合成技術（ディープフェイク）や生成AI特有の誤り（ハルシネーション）とは無関係。

## g4-09 プロンプトインジェクション／SQLインジェクション／DDoS攻撃／ブルートフォース攻撃

**問題**: 悪意のある指示を入力に紛れ込ませ、AIに本来の制限を無視した動作をさせる攻撃は？
選択肢: (0)プロンプトインジェクション（正解） / (1)SQLインジェクション / (2)DDoS攻撃 / (3)ブルートフォース攻撃

### 事実

- **プロンプトインジェクション**: OWASP「Top 10 for LLM Applications」で2023年版・2025年版ともに**第1位（LLM01）**のリスクとして位置づけられている。「A Prompt Injection Vulnerability occurs when user prompts alter the LLM's behavior or output in unintended ways.」（ユーザーのプロンプトがLLMの挙動や出力を意図しない形で変化させてしまう脆弱性）と定義。LLMは指示（instruction）とデータを明確に区別しないため、入力に紛れ込んだ命令がそのまま「指示」として実行されてしまう。直接入力によるもの（direct）だけでなく、Webページや文書など外部データにこっそり指示を仕込む「間接プロンプトインジェクション（Indirect Prompt Injection）」も明記されている。
  - 出典: [OWASP Top 10 for LLM Applications 2025 公式PDF](https://owasp.org/www-project-top-10-for-large-language-model-applications/assets/PDF/OWASP-Top-10-for-LLMs-v2025.pdf)、[OWASP Japan（owasp-ja）日本語訳リポジトリ LLM01_PromptInjection.md](https://github.com/owasp-ja/Top10-for-LLM/blob/main/1.1-ja/LLM01_PromptInjection.md)
  - 確度: 高（OWASP公式資料に基づく）

- **SQLインジェクション**: Webアプリケーションの入力値の処理不備を悪用し、想定外のSQL文をデータベースに実行させる攻撃。IPA「安全なウェブサイトの作り方」で解説されている代表的なウェブアプリケーションの脆弱性の一つ。対策としてプレースホルダ（バインド機構）の利用が推奨されている。
  - 出典: [IPA「安全なウェブサイトの作り方」1.1 SQLインジェクション](https://www.ipa.go.jp/security/vuln/websecurity/sql.html)
  - 確度: 高

- **DDoS攻撃（分散型サービス妨害攻撃）**: 攻撃者がマルウェアに感染させた多数のコンピュータ（ボットネット）を使い、標的のサーバー・ネットワークに過剰な通信を送りつけ、サービスを停止・遅延させる攻撃。IPA「情報セキュリティ10大脅威」でも組織向け脅威の一つとして継続的に取り上げられている。
  - 出典: 複数の解説記事（IPAの「情報セキュリティ10大脅威」での位置づけは複数の二次記事で言及されているが、当年版の順位そのものは今回未確認）
  - 確度: 中（DDoSの技術的定義自体は確度高だが、「情報セキュリティ10大脅威」での具体的な順位は今回IPA公式ページを直接確認できていない）

- **ブルートフォース攻撃（総当たり攻撃）**: パスワードに使用され得るすべての文字の組み合わせを順番に試して認証を突破しようとする攻撃。IPA「情報セキュリティ5か条」等で、対策として英数字記号を含む10文字以上のパスワード設定や使い回しの禁止、ログインロック・二要素認証の導入が推奨されている。
  - 確度: 中（一般的な技術解説の集約に基づく。IPA公式ページの直接引用は今回未確認）

### 出題の狙い（想定される引っかけ）
- 「インジェクション」という言葉が共通するため、プロンプトインジェクション（AI・LLM対象）とSQLインジェクション（データベース対象）を混同しやすい。両者は「本来意図されていない命令をシステムに実行させる」という構造は似ているが、対象システムが異なる（LLM vs DB）。
- DDoS攻撃・ブルートフォース攻撃は「大量のリクエスト」という点でイメージが似ているが、DDoSは**サービス停止（可用性への攻撃）**、ブルートフォースは**認証突破（機密性への攻撃）**という目的の違いがある。
