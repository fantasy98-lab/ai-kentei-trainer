## 論点1: o1（推論モデルの始まり）
- **論点**: GPT-o1（公式名は o1）
- **章**: 第2章
- **事実**: OpenAI は 2024年9月12日に、回答する前により長く考えるよう設計した新しいモデルシリーズとして o1-preview と o1-mini を発表した（公式の言い方: "a new series of AI models designed to spend more time thinking before they respond"）。製品版の o1 は API で `o1-2024-12-17`（2024年12月17日の API Changelog）。モデルページは、強化学習で訓練され、回答前に長い内部の思考の連鎖（chain of thought）を作る、と説明している。
- **出典**:
  - https://community.openai.com/t/introducing-openai-o1-preview-new-openai-announcement/937861 （OpenAI公式アナウンス投稿、2024-09-12、確認日 2026-10-15）
  - https://community.openai.com/t/new-reasoning-models-openai-o1-preview-and-o1-mini/938081 （同、確認日 2026-10-15）
  - https://developers.openai.com/api/docs/models/o1 （確認日 2026-10-15）
  - https://developers.openai.com/api/docs/models/o1-preview （スナップショット名 o1-preview-2024-09-12、確認日 2026-10-15）
  - https://developers.openai.com/api/docs/changelog （o1 API 2024-12-17、確認日 2026-10-15）
- **確度**: 高（OpenAI公式の別ページで確認）。ただし openai.com の発表本文（"Learning to reason with LLMs"）は 403 で未確認。
- **出題の狙い**:
  - 「回答前に考える（推論に時間をかける）」が o系列の特徴。GPT-4o（"o" は omni＝マルチモーダル）の "o" と、o1 の "o" は別物。この混同を狙える。
  - 誤答候補: 「画像から動画を作るモデル」（Sora と混同）、「API専用の軽量モデル」（GPT-4.1 と混同）。

  - 現在のChatGPTでの提供状況は使わない。「2024年に発表した」と時点を入れる。

- **出典**:
  - https://developers.openai.com/api/docs/changelog （2025-04-16、確認日 2026-10-15）

## 論点3: 「o4」は単独では出ていない／シラバス表記「GPT-o1」と公式名の関係
- **論点**: 表記の違い（GPT-o1, GPT-o3, GPT-o4 と o1, o3, o4-mini）
- **章**: 第2章
- **事実**: OpenAI の公式ページ（API Changelog、モデルページ）に出てくる名前は `o1`、`o3`、`o4-mini`、`o1-preview`、`o1-mini`、`o3-mini` で、「GPT-o1」という表記は確認できなかった。確認できたモデルページ（o1、o3、o4-mini、o3-mini、o1-preview）の範囲では、単独の「o4」というモデルは見当たらず、o4 系は `o4-mini` だけが載っていた。シラバスが「GPT-o4」とまとめている対象は、公式名で言えば o4-mini とみられる（後述の「事実として言える範囲」を参照）。
- **出典**: https://developers.openai.com/api/docs/models/o4-mini （「plain o4 は載っていない」ことを確認）、https://developers.openai.com/api/docs/changelog （確認日 2026-10-15）
- **確度**: 「公式名が o1 / o3 / o4-mini である」ことは高。「単独の o4 が存在しない」は、確認したページの範囲ではそう見えるという意味で、否定の言い切りは「未確認」寄り。問題文では「o4-mini（o4 の名前で出ているのは mini）」のように肯定形で書き、「o4 は存在しない」と断定しない。
- **事実として言える範囲（シラバス表記との関係）**:
  - 言える: OpenAI の公式名は「GPT-」を付けない。シラバスの「GPT-o1」などは、GPTシリーズの流れで整理するための表記と読めるが、シラバスがそう定義している根拠は未確認。
  - 言える: 公式の GPT-4o の "o" は omni で、o系列（o1 など）の "o" とは別の系統の名前。GPT-4o は o系列ではない（モデルページでは GPT-4o を "most capable model outside of the o-series" としている）。
  - 言えない（未確認）: 「o1 が GPT の一部だと OpenAI が言っている」「"o" が何の略か」。後者は公式説明を見つけられなかった。
- **出題の狙い**: 「OpenAI の公式名として正しいものは？」→ o1／o3／o4-mini が正解。誤答候補は GPT-o1、GPT-o3、GPT-o4、GPT-4o1。シラバス表記は受験対策、公式名は実務、と学べる。解説に「o4 は単独では出ていない」と書く場合は、「公式のモデルページでは o4-mini が載っている」と範囲を限定する。
