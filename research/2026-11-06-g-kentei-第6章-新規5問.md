## 本命論点（確度高）

### 論点 1. U-Net（収縮パスと拡張パス、連結によるスキップ）

- **論点**: 画像認識（26）／U-Net
- **章**: 第6章
- **事実**:
  - U-Net 論文（ar5iv の本文で確認）は、"a contracting path to capture context and a symmetric expanding path" からなるネットワークと説明する。収縮パスは 3×3 の畳み込みと 2×2 の max pooling を繰り返し、ダウンサンプリングのたびに特徴チャンネル数を2倍にする。
  - 拡張パスは、特徴マップをアップサンプリングし（2×2 の up-convolution）、収縮パスの対応する、切り抜いた特徴マップとの連結（"a concatenation with the correspondingly cropped feature map from the contracting path"）を行う。切り抜くのは、畳み込みで境界の画素が失われるため。最終層は 1×1 畳み込みで各特徴ベクトルをクラス数に写す。全結合層は使わない。
  - 論文は、注釈付きデータが少ないため、弾性変形によるデータ拡張を大量に行ったと述べる。
- **出典**: https://ar5iv.labs.arxiv.org/html/1505.04597 2026-11-06（本文確認）
- **確度**: 高
- **出題の狙い**: 「U字」の左半分（縮小して文脈を捉える）と右半分（拡大して位置を細かく戻す）、両者をつなぐ連結。誤答の素材: ResNet は同じ入力を**足し算**する（"The operation F+x is performed by a shortcut connection and element-wise addition"、https://ar5iv.labs.arxiv.org/html/1512.03385 2026-11-06 本文確認。学習する重みも計算量も増やさない、と論文は述べる）。U-Net は連結で、チャンネルが増える側。
- **注意**: 「U-Net は医療画像向け」は論文の対象（電子顕微鏡の生体画像）に基づく話で、「医療画像だけ」とは言い切らない。「最初にスキップ接続を使った」は未確認、使わない。ResNet の「足し算」と対比するときは、k5-06 の正解文（勾配、残差）を誤答にそのまま使わない。

### 論点 2. Vision Transformer（画像をパッチに分けてトークン列にする）

- **論点**: 画像認識（26）／Vision Transformer
- **章**: 第6章
- **事実**: ViT 論文（ar5iv の本文で確認）は、画像を固定サイズのパッチに分割し（"we split an image into fixed-size patches"）、各パッチを平らにして学習可能な線形射影で埋め込みベクトルにし、位置埋め込みを足し、標準の Transformer エンコーダに入れる。BERT にならい、系列の先頭に学習可能な class トークンを置き、その出力を画像の表現として分類に使う。位置埋め込みは学習可能な1次元のもの。論文は、ViT は CNN より画像固有の帰納バイアスがずっと少ない（"much less image-specific inductive bias than CNNs"）と述べる。モデル名の ViT-L/16 の 16 は、16×16 のパッチサイズ。
- **出典**: https://ar5iv.labs.arxiv.org/html/2010.11929 2026-11-06（本文確認）
- **確度**: 高
- **出題の狙い**: 「畳み込みを使わず、画像をパッチの列として Transformer に入れる」。誤答の素材: 画素1つ1つを順に RNN に入れる、画像全体を1つのベクトルにする、など。パッチを小さくすると系列が長くなり計算が増える（論文の記述）。
- **注意**: 「ViT は CNN より常に高精度」は言い切らない（論文は大規模データでの事前学習の文脈）。局所性の帰納バイアスが少ない点は、「論文が述べる」と書く。

### 論点 3. DQN の経験再生（experience replay）

- **論点**: 深層強化学習（29）／DQN
- **章**: 第6章
- **事実**: DQN 論文（ar5iv の本文で確認）は、各時刻の経験 (s, a, r, s') を複数エピソードにまたがるリプレイメモリに貯め、学習時にそこからランダムに取り出したミニバッチで Q 学習を更新する。論文は「サンプルをランダムにすると、これらの相関が崩れ、更新の分散が減る」と述べる（"randomizing the samples breaks these correlations and therefore reduces the variance of the updates"）。ネットワークの入力は前処理した直近4フレーム（84×84×4）、出力は行動ごとに1つの Q 値（1回の順伝播で全行動の Q 値が出る）。
- **出典**: https://ar5iv.labs.arxiv.org/html/1312.5602 2026-11-06（本文確認）
- **確度**: 高
- **出題の狙い**: 「連続したデータは似ていて相関が強い。ためておいてランダムに取り出し、相関を弱める」。誤答の素材: 経験を古い順に使う、行動をランダムにする（探索の話。k3-07 の ε-greedy と混ぜない）。
- **注意**: **ターゲットネットワーク**は Nature 2015 の DQN 論文で扱われるが、Nature の本文は認証ページへのリダイレクトで未確認。論点 4 のダブル DQN 論文が「既存のターゲットネットワーク」に言及しているため、「DQN にはターゲットネットワークがある」までは使える（ダブル DQN 論文の本文で確認）。「Nature 論文で初めて導入」とは言い切らない。この ar5iv 版（2013 年）で確認したのは経験再生の記述。ターゲットネットワークの記述の有無は未確認。

### 論点 4. ダブル DQN（過大評価の抑制）

- **論点**: 深層強化学習（29）／ダブル DQN
- **章**: 第6章
- **事実**: Double DQN 論文（ar5iv の本文で確認）は、Q 学習と DQN が目標値の計算に使う max 演算子は、「行動の選択と評価に同じ値を使う」（"uses the same values both to select and to evaluate an action"）ため、過大評価（"overoptimistic value estimates"）が起きやすいと述べる。Double DQN は、オンラインネットワークで最良の行動を選び、ターゲットネットワークでその行動の価値を評価する。既存のターゲットネットワークを「2つ目の価値関数」として流用する。
- **出典**: https://ar5iv.labs.arxiv.org/html/1509.06461 2026-11-06（本文確認）
- **確度**: 高
- **出題の狙い**: 「選ぶネットワークと評価するネットワークを分ける」。誤答の素材: 2つのエージェントが対戦する、Q 値を2倍にする、ネットワークを2層にする（名前に引きずられる誤答）。
- **注意**: 式（`Q(S', argmax_a Q(S', a; θ); θ⁻)`）は、問うなら言葉にする。「過大評価をなくす」と言い切らず「抑える」。ターゲットネットワークの更新間隔の数字は問わない。

### 論点 5. デュエリングネットワーク（状態価値とアドバンテージ）

- **論点**: 深層強化学習（29）／デュエリングネットワーク
- **章**: 第6章
- **事実**: Dueling 論文（ar5iv の本文で確認）は、1つの Q ネットワークの中で、状態価値 V と行動のアドバンテージ A を別々の流れ（ストリーム）で推定し、あとで合成して Q を得る。畳み込み層は共有し、その後の全結合層を2本に分ける。論文は、この分解の主な利点を「行動をまたいで学習を一般化すること」と述べる（"The main benefit of this factoring is to generalize learning across actions"）。出力の形は通常の Q ネットワークと同じなので、既存の強化学習アルゴリズムと組み合わせられる。
- **出典**: https://ar5iv.labs.arxiv.org/html/1511.06581 2026-11-06（本文確認）
- **確度**: 高
- **出題の狙い**: 「状態そのものの良さ（V）と、その状態での行動ごとの差（A）に分ける」。ダブル DQN（選択と評価の分離）と取り違えやすい。2つを選択肢に並べると見分けの問いになる。
- **注意**: 合成式の「平均を引く」は式の細部なので問わない。「アドバンテージ＝行動の価値から状態の価値を引いたもの」と説明するなら、出典の定義で再確認する（今回の取得で式 Q = V + (A − 平均A) は確認、定義文そのものは未確認）。Actor-Critic（k3-15）の Critic と混ぜない。

### 論点 6. LIME（局所的な近似による説明）

- **論点**: モデルの解釈性（33）／LIME
- **章**: 第6章
- **事実**: LIME 論文（ar5iv の本文で確認）は、説明に3つの条件を求める。人が理解できる表現（文章なら単語の有無、画像ならスーパーピクセルの有無）、予測対象の近くでモデルの振る舞いと合うこと（局所忠実性。"it must correspond to how the model behaves in the vicinity of the instance being predicted"）、元のモデルを黒箱として扱うこと（model-agnostic）。仕組みは、説明したい1件の周りで特徴の一部を落とした摂動サンプルを作り、元のモデルで予測し、元のデータに近いほど重くして、疎な線形モデルを学習する。
- **出典**: https://ar5iv.labs.arxiv.org/html/1602.04938 2026-11-06（本文確認）
- **確度**: 高
- **出題の狙い**: 「モデル全体ではなく、1つの予測の近くだけを、単純で解釈しやすいモデルで近似」。誤答の素材: モデル全体を線形モデルに置き換える、学習データ全体の重要度を出す、勾配で注目画素を示す（Grad-CAM の説明）。
- **注意（重複）**: Grad-CAM（k6-08 の正解）と Permutation Importance（k6-08 の誤答）の説明を、選択肢にそのまま使わない。「LIME は線形モデルを使う」は論文の実装の記述。「近似するモデルは必ず線形」とは言い切らない。

### 論点 7. SHAP（シャープレイ値による特徴量の寄与）

- **論点**: モデルの解釈性（33）／SHAP
- **章**: 第6章
- **事実**: SHAP 論文（ar5iv の本文で確認）は、SHAP を「各特徴量に、特定の予測に対する重要度を割り当てる」ものとして位置づける（"SHAP assigns each feature an importance value for a particular prediction"）。加法的な特徴量寄与の手法（説明モデルが二値変数の線形関数）のうち、局所的正確性・欠損性・一貫性の3つの性質を満たすのは Shapley 値に基づく値で、これを SHAP 値と呼ぶ。LIME を含む既存の6手法を、この枠組み（加法的特徴量寄与）に位置づける。論文は、LIME の損失やカーネルなどの選び方は経験的（heuristic）で、Shapley 値は復元されないと指摘する。Kernel SHAP は、重み付きの線形回帰で Shapley 値を求める。
- **出典**: https://ar5iv.labs.arxiv.org/html/1705.07874 2026-11-06（本文確認）
- **確度**: 高
- **出題の狙い**: 「ゲーム理論のシャープレイ値に基づき、各特徴量が予測にどれだけ寄与したかを配分」。LIME（1件の近くで近似）と取り違えやすい。「全体の重要度」ではなく「1つの予測ごとの寄与」。
- **注意**: 「LIME より SHAP の方が必ず良い」は言い切らない。Shapley 値の計算式は問わない。「Shapley 値だけが3性質を満たす」は論文の定理で、加法的手法という条件つき。

### 論点 8. TF-IDF（概念）

- **論点**: 自然言語処理（27）／TF-IDF
- **章**: 第6章
- **事実**: scikit-learn の公式ユーザーガイドは、tf-idf を「単語の出現頻度（term-frequency）に、逆文書頻度（inverse document-frequency）を掛けたもの」と定義し、"the" "a" "is" のように多くの文書に出る語は文書の中身の情報が少ないので、そのままの出現回数ではまれで重要な語が埋もれてしまう、と説明する。tf-idf はこうした語の重みを下げるために使う。
- **出典**: https://scikit-learn.org/stable/modules/feature_extraction.html （「Tf–idf term weighting」節。本文確認）2026-11-06
- **確度**: 高（概念「tf × idf、多くの文書に出る語は重みが下がる」まで）。**計算の式は確度中（作問に回さない）**: 同ドキュメントの idf はデフォルトで `log((1+n)/(1+df)) + 1`（smooth_idf）。同ドキュメントは教科書の定義を `log(n/(1+df))` と書くが、教科書では `log(n/df)` とする説明もあり、資料で食い違う。Stanford の IR 教科書（nlp.stanford.edu/IR-book）は 2026-11-06 に接続拒否（ECONNREFUSED）で本文を確認できず、PDF も読めなかった。**計算問題にするなら、問題文に idf の定義式を書き、その式の計算を問う形にする。教科書の定義を正解の根拠にしない。**
- **出題の狙い**: 「その文書によく出て、ほかの文書にあまり出ない語ほど値が大きい」。「全文書に出る語は idf が小さい」。誤答の素材: 出現回数が多い語ほど必ず高い（tf だけの考え）、まれな語ほど低い。
- **注意**: 「idf は常に正」「log の底」は資料により違うので使わない。「TF-IDF は単語の意味を捉える」とは言い切らない（出現頻度の統計）。

### 論点 9. CLIP の考え方（画像とテキストの対比学習、ゼロショット分類）

- **論点**: マルチモーダル（32）／CLIP、Zero-shot
- **章**: 第6章
- **事実**: CLIP 論文（ar5iv の本文で確認）は、インターネットから集めた約4億組の（画像、テキスト）で事前学習する。バッチ内の N 組から N×N 通りの組み合わせを作り、正しい N 組の画像とテキストの埋め込みのコサイン類似度を最大にし、残りの誤った組を小さくするように、画像エンコーダとテキストエンコーダを同時に学習する。ゼロショット分類では、データセットの全クラス名をテキストにして埋め込み、入力画像と最も類似度の高いクラスを選ぶ。
- **出典**: https://ar5iv.labs.arxiv.org/html/2103.00020 2026-11-06（本文確認。ただし本文は長く、先頭〜20万字目までを確認。zero-shot の節の定義文と "A photo of a {label}" のテンプレートの原文は未確認）
- **確度**: 高（上の記述の範囲）
- **出題の狙い**: 「対応する画像とテキストの埋め込みを近づけ、対応しない組を遠ざける」「クラスごとの教師データなしで、クラス名のテキストと比べて分類できる」。誤答の素材: 画像からキャプション文を生成する（Image Captioning）、テキストから画像を生成する。VQA（k6-07 の正解）の説明は使わない。
- **注意**: 手法名はシラバスのキーワードなので CLIP と書いてよいが、問題文は「画像とテキストの対比学習」でも成り立つ作りにする。「ゼロショット」は genai のプロンプトの Zero-shot と文脈が違うため、問題文に「画像分類で」と明記する。「4億組」は数字として正確だが、正解に不要なので解説には入れない方が安全。

### 論点 10. 宝くじ仮説

- **論点**: モデルの軽量化（34）／宝くじ仮説
- **章**: 第6章
- **事実**: 論文（ar5iv の本文で確認）は、「密で、重みをランダムに初期化した順伝播型ネットワークは、単独で学習すると元のネットワークと同程度のテスト精度に達する部分ネットワーク（winning tickets）を含む」と主張する。見つけ方は、学習してから、重みの絶対値が小さいものを削り、残った結合を**学習前の元の初期値に戻す**。部分ネットワークの構造だけを残して重みをランダムに初期化し直すと、性能が元のネットワークに及ばなくなる（初期値が効く。"initialization is crucial for the efficacy of a winning ticket"）と述べる。
- **出典**: https://ar5iv.labs.arxiv.org/html/1803.03635 2026-11-06（本文確認。ただし本文の最後の約4万字は未読）
- **確度**: 高
- **出題の狙い**: 「大きなネットワークの中に、小さくても同じくらい学習できる部分ネットワークがある」「元の初期値が重要」。プルーニングや蒸留との混同。誤答の素材: 学習率を大きくすると当たりが出る、ネットワークをランダムに増やす。
- **注意（重複）**: k6-09 の誤答に「重みの大きさに基づいて、不要な結合を削る」（プルーニング）がある。宝くじ仮説の見つけ方の説明はこの文と近い。選択肢にプルーニングの説明を使わず、「初期値」を核にする。「宝くじ仮説は常に成り立つ」とは言い切らない（論文は仮説。条件つきの観察）。

### 論点 11. NeRF（ニューラル放射場）

- **論点**: データ生成（30）／NeRF
- **章**: 第6章
- **事実**: NeRF 論文（ar5iv の本文で確認）は、場面を、3次元の位置 (x, y, z) と視線方向の5次元座標を入力とし、その点の体積密度と色を出力する全結合ネットワーク（畳み込みを使わない）で表す。古典的なボリュームレンダリングで、カメラからの光線上の点の色を積分して画素の色を出す。この処理が微分可能なので、勾配降下法で学習できる。学習に必要なのは、カメラの位置・向きが既知の画像の集合だけ（"the only input required to optimize our representation is a set of images with known camera poses"）。学習後は、学習に使っていない視点の画像を合成できる（新規視点合成）。位置エンコーディングは、入力座標を高周波の表現に写し、細かい変化を表現しやすくする。
- **出典**: https://ar5iv.labs.arxiv.org/html/2003.08934 2026-11-06（本文確認）
- **確度**: 高
- **出題の狙い**: 「複数視点の画像から、場面そのものを連続的な関数（ネットワーク）として学び、新しい視点の画像を描く」。誤答の素材: 3次元の点群やメッシュを直接出力する、1枚の画像から深度を推定する、画像のスタイルを変換する（k6-05 の CycleGAN の文は流用しない）。
- **注意**: 「1枚の画像から3Dを作れる」は原論文の方法には当てはまらない。後続研究に例外があるので、問題文は「NeRF の原論文の方法では」と書くか、断定を避ける。位置エンコーディングは Transformer のもの（genai g2-25）とは別の文脈。NeRF の問題では混ぜない。

### 論点 12. オフライン強化学習

- **論点**: 深層強化学習（29）／オフライン強化学習
- **章**: 第6章
- **事実**: Levine ほかのチュートリアル（ar5iv の本文で確認）は、オフライン強化学習を、事前に集めたデータだけを使い、追加のオンラインのデータ収集をしない強化学習として説明する（"reinforcement learning algorithms that utilize previously collected data, without additional online data collection"）。静的な遷移データセットが与えられる。中心の課題は分布シフト（学習した方策が、データを集めた方策と違う行動をとり、データの分布から外れる）。データに高報酬の領域がなければ、探索で見つけることはできない。
- **出典**: https://ar5iv.labs.arxiv.org/html/2005.01643 2026-11-06（本文確認。ただし先頭 10万字のみ。後半は未読）
- **確度**: 高
- **出題の狙い**: 「環境と新しくやり取りせず、すでにあるログのデータから学ぶ」。誤答の素材: シミュレータで大量に試行する（sim2real。k6-04）、人間のフィードバックで報酬モデルを作る（RLHF。genai g2-14/g2-21）、ラベル付きデータから教師あり学習する。
- **注意**: 「オフライン強化学習は教師あり学習と同じ」とは言い切らない。「実環境で試すのが危険・高コストだから使う」という利点は、今回取得した範囲では確認できていない（未確認）。使うなら原文で再確認する。k6-04 と RLHF の既存の正解文を、誤答にそのまま流用しない。

### 論点 13. MFCC とメル尺度（**確度：中、作問に回さない**）

- **論点**: 音声処理（28）／メル周波数ケプストラム係数（MFCC）、メル尺度
- **章**: 第6章
- **事実**:
  - メル尺度は、人の周波数の知覚（音の高さの感じ方）に合わせた尺度。CCRMA（Stanford）の資料は、「1 kHz の純音で、聴覚の閾値より40 dB 大きいものの高さを 1000 mel と定める」と書く。
