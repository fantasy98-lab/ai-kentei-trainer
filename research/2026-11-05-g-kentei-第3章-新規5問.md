## 論点 A（計算向け・推奨）正解率の落とし穴と再現率・適合率の計算

- **論点**: 混同行列、正解率、適合率、再現率、偽陽性、偽陰性、不均衡データ
- **章**: 第3章（モデルの選択・評価）
- **事実**:
  - 正解率 = (TP+TN)/(TP+TN+FP+FN)。再現率 = TP/(TP+FN)。適合率 = TP/(TP+FP)。偽陽性率 FPR = FP/(FP+TN)。F1 = 2TP/(2TP+FP+FN)。
  - 陽性が1%のデータで、常に陰性と予測するモデルは正解率99%になる。Google は不均衡データでは正解率を避けるよう助言（"Avoid for imbalanced datasets"）。
  - sklearn: 再現率は「sensitivity」とも呼ばれる。
- **出典**:
  - https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall （式・不均衡データの記述を取得）2026-11-05
  - https://scikit-learn.org/stable/modules/model_evaluation.html （precision=tp/(tp+fp)、recall=tp/(tp+fn)、F_β の式を取得）2026-11-05
- **確度**: 高
- **作問に使える数値例（作問側の計算・検算済み。k3-08 の数値とは別）**: 1000件、実際の陽性20件。TP=5、FN=15、FP=5、TN=975（合計1000）。
  - 正解率 = 980/1000 = 0.98
  - 再現率 = 5/20 = 0.25
  - 適合率 = 5/(5+5) = 0.5
  - 偽陽性率 = 5/980 ≈ 0.0051
  - 問い方案: 「正解率98%なのに再現率が25%。何が起きているか／再現率はいくつか」。
- **出題の狙い**: 適合率（分母＝陽性と予測した数 TP+FP）と再現率（分母＝実際の陽性 TP+FN）の取り違え。正解率が高い＝良いモデルという思い込み。偽陽性（陰性を陽性と誤る）と偽陰性（陽性を陰性と誤る）の取り違え。
- **言い切り注意**: 「再現率と適合率のどちらを重視すべきか」は用途次第。混同行列の行列の向きは資料で違うので問わない。Google の「しばしば逆の関係」は「必ず」と言わない。

## 論点 B（計算向け）回帰の評価指標 MSE / RMSE / MAE

- **論点**: 平均二乗誤差 (MSE)、二乗平均平方根誤差 (RMSE)、平均絶対誤差 (MAE)
- **章**: 第3章（モデルの選択・評価、回帰）
- **事実**: MSE = (1/n)Σ(y_i − ŷ_i)²（二乗誤差の平均）。MAE = (1/n)Σ|y_i − ŷ_i|（絶対誤差の平均）。RMSE は MSE の平方根で、目的変数と同じ単位になる。sklearn の例: y=[3,−0.5,2,7]、予測=[2.5,0.0,2,8] で MSE=0.375、MAE=0.5。
- **出典**: https://scikit-learn.org/stable/modules/model_evaluation.html （offset 100000 以降の回帰指標の節。式・RMSE の説明・例の値を取得）2026-11-05
- **確度**: 高（定義・式）。
  - **外れ値への感度**: sklearn のページには MSE/RMSE/MAE の外れ値感度の明示記述なし（median_absolute_error が外れ値に頑健との記述のみ）。「MSE は二乗するので大きな誤差の影響が大きい」は式からの推論。**作問では「式から計算で示す」形にし、「外れ値に弱いと一次情報が述べている」とは書かない。確度「中」扱い（言葉での一般論）。**
- **作問に使える数値例（作問側の計算・検算済み）**: 4件のデータ。
  - 予測の誤差（予測−実測）が (2, 2, 2, 2) のモデルA: MAE=2、MSE=4、RMSE=2。
  - 誤差が (0, 0, 0, 8) のモデルB: MAE=2、MSE=64/4=16、RMSE=4。
  - 同じ MAE=2 でも MSE・RMSE は B が大きい（大きな誤差が1つあると効く）。
  - 別案: 実測 [10,20,30,40]、予測 [12,18,30,50] → 誤差 (2,−2,0,10)。MAE=14/4=3.5、MSE=108/4=27、RMSE=√27≈5.20。
- **出題の狙い**: 平方根を取り忘れる（MSE と RMSE の混同）、絶対値と二乗の混同。RMSE は目的変数と同じ単位。
- **言い切り注意**: 「MAE のほうが常に良い指標」とは言わない。分類の指標（正解率など）との混同を誤答に使える。

## 論点 C（計算向け）割引率と割引累積報酬

- **論点**: 割引率、収益（割引後の報酬の合計）、マルコフ決定過程
- **章**: 第3章（強化学習）
- **事実**: 割引率 γ のとき、時刻 t の報酬は γ^t R として数える。割引後の効用は U = R(s0,a0,s1) + γR(s1,a1,s2) + γ²R(s2,a2,s3) + …。γ は 0<γ<1 を通常用いる。γ が小さいほど将来の報酬の価値が小さくなる（目先重視は、指数的減衰からの説明。Berkeley は「小さい γ」を直接説明していない）。
- **出典**: https://inst.eecs.berkeley.edu/~cs188/textbook/mdp/markov-decision-processes.html （UC Berkeley CS188。割引の定義と式を取得。数値例は掲載なし）2026-11-05
- **確度**: 高（式）。「γ が小さいほど目先重視」は 2026-10-03 のメモで同ページ等で確認済みとして記録されているが、今回の取得では明示的でなかった。**式から計算して示す形で使う。**
- **作問に使える数値例（作問側の計算）**:
  - 報酬列 (5, 10, 20)、γ=0.5、最初の報酬は割り引かない: 5 + 0.5×10 + 0.25×20 = 5+5+5 = 15。
  - 報酬列 (0, 0, 10)、γ=0.9: 0 + 0 + 0.81×10 = 8.1。γ=0.5 なら 2.5。
- **出題の狙い**: 最初の報酬を割り引くか（t=0 で γ^0=1）。γ を掛ける回数の数え間違い（2番目の報酬は γ^1、3番目は γ^2）。**教科書により添字の書き方（R_{t+1} から始める等）が違うので、問題文に「最初の報酬は割り引かない」と明記する。**
- **言い切り注意**: γ の典型値（0.99 など）は使わない。割引率の記号は β 等の場合もあるので「割引率」と書く。

## 論点 D（知識）AIC と BIC

- **論点**: 赤池情報量規準 (AIC)、ベイズ情報量規準 (BIC)
- **章**: 第3章（モデルの選択・評価）
- **事実**: AIC = −2 log(L̂) + 2d、BIC = −2 log(L̂) + log(N)·d（L̂＝最大尤度、d＝パラメータ数、N＝サンプル数）。BIC は AIC の定数 2 を log(N) に置き換えたもの。いずれもモデルの柔軟さ（複雑さ）で、訓練データ上のよすぎる評価を罰する（penalize）。
- **出典**: https://scikit-learn.org/stable/modules/linear_model.html （§1.1.3.2.2–1.1.3.2.3 を取得）2026-11-05
  - 補足: https://scikit-learn.org/stable/auto_examples/linear_model/plot_lasso_lars_ic.html （AIC/BIC は訓練データ上で計算され、交差検証とは違う、と記述）2026-11-05
- **確度**: 式・複雑さの罰則＝高。
  - **「値が小さいほどよい」**: 取得した sklearn の文面には明記なし（式からは最小化の対象と読めるが、記述としては未確認）。検索結果の要約（Penn State STAT 501 Lesson10 が「値の低いほうを選ぶ」と述べる旨）は得たが、同サイトは証明書エラーで本文を取得できず、Stanford Hastie のスライドは PDF が読めなかった。**確度「中」。正解の根拠に使うなら、校閲で ISLR（hastie.su.domains/ISLR2/）等の本文で再確認すること。**
  - **「BIC のほうが罰則が重い（N>7）」**: sklearn の本文に記述なし（式から log(N)>2 は N>約7で成り立つ、は数学的事実）。式から導く形でのみ使う。
  - **オッカムの剃刀**: 一次情報で確認できず。**未確認、使わない。**
- **作問に使える数値例（作問側の計算）**: N=100、ln100≈4.605。モデルA（logL=−100、d=3）、モデルB（logL=−96、d=6）。AIC: A=200+6=206、B=192+12=204（Bが小さい）。BIC: A=200+3×4.605≈213.8、B=192+6×4.605≈219.6（Aが小さい）。ただし G検定として計算まで問うのは重い。**知識問題（「当てはまりと複雑さのバランスを見る指標」「訓練データ上の誤差だけで選ぶと複雑なモデルが選ばれやすい」）にとどめるのが無難。**
- **出題の狙い**: AIC と BIC の罰則の違い（2d と log(N)·d）。「尤度が大きいほど良い」とだけ考える誤り。交差検証との違い（AIC/BIC は訓練データ上の計算で、検証データを分けない）。
- **言い切り注意**: sklearn は AIC/BIC が漸近結果で、正しいモデルが候補に含まれる仮定、特徴量が標本より多い状態では破綻しやすい、と注意している。「常に最良のモデルを選べる」とは言わない。

## 論点 E（知識）ロジスティック回帰（再利用）

- **論点**: ロジスティック回帰
- **章**: 第3章（教師あり学習）
- **事実**: 名前に「回帰」とあるが分類のための線形モデル。特徴量の線形結合 z（対数オッズ）をシグモイド関数 1/(1+e^−z) に通し、0〜1 の確率を出力する。確率はそのまま、またはしきい値で2値に変換して使う。線形回帰は残差の二乗和を最小化する。
- **出典**: https://developers.google.com/machine-learning/crash-course/logistic-regression/sigmoid-function ／ https://scikit-learn.org/stable/modules/linear_model.html （いずれも 2026-10-03 に確認。今回は linear_model.html を再取得したが、この論点の箇所は再確認していない）
- **確度**: 高（再利用）
- **出題の狙い**: 「回帰」という名前に引っ張られて回帰問題の手法と答える誤り。シグモイド出力が 0〜1 であること（−∞〜∞ ではない）。例はスパム（k2-07）を避ける。
- **言い切り注意**: 「2クラス専用」とは言わない。

## 論点 F（知識）ウォード法（再利用）

- **論点**: ウォード法、デンドログラム
- **章**: 第3章（教師なし学習）
- **事実**: 階層的クラスタリングの併合基準の一つ。併合のたびに、全クラスタ内の二乗差の和（分散）が最小になるよう選ぶ。併合の過程を木で示す図がデンドログラム。他の基準: 最長距離法、平均法、最短距離法。
- **出典**: https://scikit-learn.org/stable/modules/clustering.html （2026-10-03 確認。今回は再取得せず）
- **確度**: 高（再利用。校閲で再確認）
- **出題の狙い**: ウォード法と最短距離法（最も近い点どうし）・最長距離法（最も遠い点どうし）の混同。k-means（階層を作らない）との違い。k3-03 の選択肢にウォード法の語があるので、整合を確認。
- **言い切り注意**: 「階層的クラスタリングはクラスタ数の指定が不要」とは言わない。

## 論点 G（知識）UCB 方策（再利用）

- **論点**: UCB 方策（バンディット）
- **章**: 第3章（強化学習）
- **事実**: 各行動の「平均報酬＋信頼区間の幅（探索ボーナス）」が最大の行動を選ぶ。UCB1 の指標は μ̂_i + √(2 ln t / T_i(t))。選んだ回数が少ない行動ほどボーナスが大きい。
- **出典**: https://ar5iv.labs.arxiv.org/html/1312.7308 （Jamieson ほか。2026-10-03 確認。今回は再取得せず）
- **確度**: 高（再利用）。Auer らの原論文は未確認。
- **出題の狙い**: 平均報酬だけで選ぶ（貪欲）との混同。ε-greedy（k3-07 で既出）との違い（ランダムに探索するか、不確かさで探索するか）。k3-07 の選択肢にUCBがあるため、重複に注意。
- **言い切り注意**: 「UCB が ε-greedy より常に優れる」は使わない。

## 論点 H（知識）ホールドアウト検証（再利用）

- **論点**: ホールドアウト検証、汎化性能
- **章**: 第3章（モデルの選択・評価）
- **事実**: 同じデータで学習と評価をするのは方法上の誤り（訓練データを丸暗記したモデルは満点になるが、未知データでは役に立たない）。データの一部を評価用（テストデータ）に取っておくのがホールドアウト検証。3分割（訓練・検証・テスト）では学習に使えるデータが減り、結果が分け方に左右される。
- **出典**: https://scikit-learn.org/stable/modules/cross_validation.html （2026-10-03 確認。今回は再取得せず）
- **確度**: 高（再利用）
- **出題の狙い**: k3-09（k-分割交差検証）との重複を避け、「訓練データでの精度は汎化性能の指標にならない」を中心にする。genai の過学習問題と近い点に注意。
- **言い切り注意**: 「ホールドアウトは交差検証より劣る」とは言わない。

## 論点 I（知識・予備）方策勾配法・Actor-Critic（再利用）

- **事実**: 方策勾配法は方策を直接パラメータ化し、期待収益を勾配上昇で最大化する。Actor-Critic は、Actor（方策）と Critic（価値関数で行動の良さを評価）の組み合わせで、REINFORCE の分散を減らす。

- **確度**: 高（再利用）
- **出題の狙い**: Actor と Critic の役割の取り違え。
